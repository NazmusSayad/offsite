---
title: Images, videos and audio
description: Show files inline in a reply.
---

OffSite shows images, videos and audio inline when a reply links to a file with Markdown image syntax:

```md
![Header](/absolute/path/header.png)
![Header](./relative/path/header.png)
```

Relative paths start at the project folder.

OffSite teaches agents this syntax with its built-in `show` skill, so you can ask for a screenshot or a recording and see it in the thread.
